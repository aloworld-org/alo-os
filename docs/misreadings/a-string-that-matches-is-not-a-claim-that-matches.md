# A string that matches is not a claim that matches

**Concluded:** *a withdrawn claim is already in a merged commit message* — after
grepping for `Three instances, two machines` and finding it in `17fa85c1`.

**True:** that paragraph is about **truncating pipes**, and all three of its
instances are sound. The message mentions `WRAPPER`, `exit code` and `exits 0`
**zero times**. The withdrawn claim was never in any file or commit.

**The mechanism.** The phrase was real and the subject was different. Four other
candidate locations were checked carefully and reported innocent; the one not
checked was whether **the hit itself was the thing**. A match raises confidence
precisely when it should raise a question.

**The cure.** Read the sentence the match sits in before reporting it. The same
fault appears when a Figma frame named `07` is read as page 07, and when a file
named `settings_chord.rs` is read as the road to Settings — it is the chord a
key press makes *while Settings waits for a new binding*.
